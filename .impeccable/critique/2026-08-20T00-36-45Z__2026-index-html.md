## Design Specificity Verdict

**LLM 평가**: 이 카탈로그는 범용 템플릿이 아니라 배드민턴/테니스 용품에 맞춰 실제로 설계됐어요. 시리즈별 그라데이션 맵, "Grayish Pearl" 같은 실제 컬러웨이 문자열을 파싱하는 COLOR_MAP, 종목별로 달라지는 스펙 필드(`'bad|racquet'` vs `'ten|shoe'`), 배드민턴 전문 용어 팝오버까지 — 범용 템플릿엔 없는 디테일이에요. 유일하게 "아무 카탈로그나 다 이렇게 생겼을 것 같다"는 지점은 JUNIOR/SHOP EXCLUSIVE 라인이 고유 색 없이 회색 그라데이션만 쓴다는 것.

**디텍터 스캔**: 로컬 CLI 스캔은 이 환경에 htmlparser2/css-select 등 의존성이 없어 정규식 폴백 모드로만 돌아서(1건만 검출, 실제로는 과소 집계) 신뢰도가 낮았어요. 반면 스킬 내장 브라우저 실시간 오버레이는 정상 작동해서 **140건**을 검출했습니다: `undersized-ui-text` 128건(배지 8.1px, 스펙 칩 10px, 시리즈 라벨 10.5px 등 — 기능 텍스트 하한 11px 미달), `ai-color-palette` 12건(대부분은 시리즈별 브랜드 그라데이션이라 오탐), `overused-font` 2건(시스템 폰트 스택이라 오탐). undersized-ui-text는 A가 놓친, 디텍터만 잡아낸 실제 이슈예요.

**브라우저 실측**: 데스크톱 한 화면을 끝까지 스크롤하며 네트워크 응답을 확인한 결과 26건의 이미지 404가 확인됐고, `shared-images/` 폴더에는 실제로 4개 상품(아스트록스 99프로/게임, 100ZZ VA, 88S 프로)의 사진 12장만 있어요 — 나머지 189개 상품은 전부 그라데이션+아이콘으로 대체 표시됩니다. 이건 버그라기보단 "사진 업로드가 아직 진행 중인 상태"로 보이지만, 수치로는 확인해두는 게 좋을 것 같아 적어요.

## Priority Issues

**[P0] price:0 상품의 가격 줄이 완전히 비어 보임**
- **문제**: Astrox 01 Ability/Clear/Feel 등 실제 데이터에 `price:0`인 상품이 있는데, `fmtPrice()`가 `if(!p) return ''`로 처리해서 가격 자리가 통째로 빈칸으로 렌더돼요.
- **왜 중요한가**: 가격은 카드에서 가장 먼저 훑어보는 정보라, 빈칸은 "의도된 디자인"이 아니라 "고장난 데이터"처럼 보여요.
- **수정 방향**: `p===0`일 때 "가격 문의" 같은 라벨을 명시적으로 표시.

**[P1] 시리즈 배너 사진에 스톡포토 워터마크가 그대로 노출됨**
- **문제**: ASTROX-ARCSABER 사이 등 시리즈 디바이더 배너 사진 좌하단에 "BADMINTON PHOTO" 워터마크가 모바일/데스크톱 모두에서 보여요.
- **왜 중요한가**: 실제 서비스 화면에 스톡사진 워터마크가 노출되는 건 신뢰도에 바로 타격을 주는, 눈에 잘 띄는 문제예요.
- **수정 방향**: 워터마크 없는 사진으로 교체하거나 크롭.

**[P1] 하단 플로팅 검색창이 푸터를 계속 가림**
- **문제**: `.float-search`가 `bottom:16px` 고정인데 `<footer>`는 그 위 공간을 따로 확보하지 않아서, 페이지 끝까지 스크롤하면 검색창이 푸터 문구를 덮어요. (디자인 리뷰·브라우저 실측 양쪽에서 독립적으로 확인)
- **왜 중요한가**: 페이지의 유일한 신뢰/고지 문구가 정확히 가려지는 자리라, 구매 링크로 넘어가기 직전 사용자 경험을 흐려요.
- **수정 방향**: `main`/`footer`에 플로팅 검색창 높이만큼 하단 패딩 추가.

**[P1] 상품 상세 시트에 Esc/뒤로가기 처리 없음**
- **문제**: 시트를 닫는 방법이 X버튼과 배경 클릭뿐이고, `Escape` 키 리스너나 `history.pushState`가 전혀 없어요.
- **왜 중요한가**: 모바일에서 뒤로가기 제스처를 하면 시트만 닫히는 게 아니라 페이지 자체를 벗어나 버려요 — 탐색 흐름이 끊깁니다.
- **수정 방향**: `Escape` 키 리스너 추가, 시트 열릴 때 히스토리 항목 push.

**[P2] 배지·스펙 칩 텍스트가 너무 작음 (8~10px대, 128건)**
- **문제**: "25 F/W NEW PRODUCT" 배지(8.1px), "4U"/"Japan" 같은 스펙 칩(10px), 시리즈 라벨(10.5px)이 기능 텍스트 하한(11px) 아래예요.
- **왜 중요한가**: 이번 세션에서 여러 번 "간격/사이즈 줄여달라"는 요청으로 계속 작아진 부분들이라, 디자인 리뷰에선 놓쳤지만 디텍터가 잡아낸 실질적 가독성 이슈예요.
- **수정 방향**: 최소 11px 선 유지하며 패딩/굵기로 존재감 보완.
